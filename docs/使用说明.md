# KeyBox 使用说明

## 一、安装与首次设置

1. 安装 APK 后打开 KeyBox
2. 设置你的**主密码**（至少 12 位，建议使用密码短语，如 `正确-马-电池-订书钉`）
3. **重要**：主密码无法找回，请务必牢记或使用应急方式妥善保存

> ⚠️ KeyBox 不提供任何"找回主密码"功能——这恰恰是安全性的体现。忘记主密码 = 数据永久无法解密。

## 二、日常使用

### 添加账号
- 首页点右下角 `+`
- 填写名称、网址、用户名、密码（可用生成器）
- 可选：分类、标签、2FA 密钥、备注

### 查找账号
- 首页顶部搜索框输入关键词（名称/网址/用户名）
- 可按分类或标签筛选

### 复制密码
- 进入账号详情，点击用户名/密码旁的复制图标
- 密码复制后 **30 秒自动清除**剪贴板

## 三、安全功能

### 自动锁定
- 切到后台或锁屏时**立即锁定**
- 前台无操作超时自动锁定（可在设置中调整：1/5/15/30 分钟/手动）

### 生物识别解锁
- 设置 → 安全 → 打开"生物识别解锁"
- 之后可用指纹/面部快速解锁
- 新增/删除指纹后需重新输入主密码（安全机制）

### 自动填充（Autofill）
1. 设置 → 自动填充 → 打开开关
2. 点"前往系统设置启用"，选择 KeyBox
3. 之后在其他 App 登录页点击输入框即可自动填充

## 四、2FA（双因素认证）

1. 在服务商后台开启 2FA，复制其提供的 **Base32 密钥**
2. 在 KeyBox 编辑账号，把密钥粘贴到"2FA 密钥"字段
3. 账号详情页会显示 **6 位动态验证码**（30 秒自动刷新）

## 五、备份与迁移

### 导出备份（重要！）
- 设置 → 备份与迁移 → 导出加密备份
- 输入主密码验证，生成 `.kbx` 文件
- 备份文件已加密，但仍请存放到自己控制的介质

### 恢复备份
- 新手机安装 KeyBox → 设置 → 导入备份 → 选择 `.kbx` → 输入**导出时使用的主密码**

### 迁移旧密码
- 从浏览器/其他管理器导出 CSV → KeyBox 导入 CSV
- 导入后建议删除源 CSV 文件

## 六、安全中心

- 设置 → 安全中心
- 检查弱密码、重复密码、长期未修改（超过 180 天）
- 全部在本地完成，密码从未上传

## 七、重要提醒

1. **主密码是唯一钥匙**：忘记即无法恢复
2. **定期备份**：本地数据在，换机/丢机才不慌
3. **妥善保管备份文件**：虽已加密，但泄露后可被离线破解，安全性取决于主密码强度
4. KeyBox **完全离线**，不联网、不上传任何数据
